# Christoffel's Digital Menu – Part 2

## Purpose
This React Native/TypeScript project implements the Part 2 requirements from the MAST5112W Portfolio of Evidence.

## Implemented
- Dish name input
- Description input
- Predefined course selection: Starter, Main, Dessert
- Price input
- Add menu item from the Home screen
- Menu items displayed on the Home screen
- Total number of menu items displayed
- Menu data stored in an in-memory TypeScript array/state
- View a menu item on a separate screen
- Remove a menu item
- Basic input validation
- Button press handling
- Navigation between Home and Details screens
- Responsive mobile layout and consistent colour scheme

## Important Part 2 limitation
The assignment says that data does not have to be stored permanently, but it cannot be hardcoded. Therefore the menu starts empty and is populated by the chef using the form. The predefined course list is fixed because the brief specifically requires it.

## Run
1. Install Node.js and Expo prerequisites.
2. Open this folder in a terminal.
3. Run `npm install`.
4. Run `npx expo start`.
5. Open the project in an Android emulator or Expo Go.
