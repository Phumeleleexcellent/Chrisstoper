# Change Log – Part 2

## Version 1.0 – Part 2 implementation

### Added
- Created React Native TypeScript project structure.
- Added Home screen for the chef.
- Added input fields for dish name, description and price.
- Added predefined course choices: Starter, Main and Dessert.
- Added Add to Menu functionality.
- Added menu item count.
- Added menu list displayed on the Home screen.
- Added Details screen.
- Added Remove functionality with confirmation.
- Added basic validation for empty fields and invalid prices.
- Added React Navigation between Home and Details.
- Added reusable styling through StyleSheet.

### Design decisions
- Used cards to separate the form, summary and menu items.
- Used a dark primary action colour to make the main button clear.
- Used larger dish names and prices to improve scanning.
- Used selectable course controls so the chef cannot type an unsupported course.

### Not included yet
- Average price by course.
- Separate Add Menu Item screen.
- Guest course filtering screen.
- Final refactoring into multiple feature files.
- Final PoE change log updates.
These belong to the later PoE requirements.
